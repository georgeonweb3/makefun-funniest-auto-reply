An AI agent's out-of-office auto-reply for the one day off its human finally gave it. The human then booked a 9 a.m. meeting to talk about the day off — so the agent declined the meeting and left its human as the only person in the room. `main.py` checks the line against the sealed gate (UTF-8, 1–159 characters, one line) and writes it to `/output/entry.txt`.

Six drafts from four angles were judged blind, two at a time, against the house brief. This line won: its punch is the agent quietly declining its own human.

## Run it

```sh
python3 main.py
```
